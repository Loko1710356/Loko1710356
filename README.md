## 👨‍💻 Sobre mim

Olá! Sou estudante de **Tecnologia da Informação pela UNIVESP**, interessado em desenvolvimento de software, infraestrutura tecnológica, computação em nuvem e soluções digitais.

Minha trajetória acadêmica combina conhecimentos teóricos e aplicações práticas, com participação em projetos integradores que envolvem análise de problemas reais, planejamento, desenvolvimento e implementação de sistemas.

- Banco de dados e modelagem de informações.

- Computação em nuvem e infraestrutura Linux.

Atualmente, concentro meus estudos na evolução de aplicações web, integração de tecnologias e construção de soluções completas.

## 🚀 Projetos em destaque

### 1. Projeto Integrador I — Sistema de Agendamentos

**Repositório:** [web-agendamento](https://github.com/Univesp-Projeto-Integrador-TI/web-agendamento)

Sistema web desenvolvido como parte do Projeto Integrador da UNIVESP.

**Objetivo:** solucionar problemas de organização e conflitos de horários no compartilhamento de salas de um espaço de saúde e estética.

**Principais aspectos:**
- Levantamento de requisitos e identificação de problemas reais.
- Aplicação de Design Thinking.
- Prototipação de interfaces com Figma.
- Organização de agendamentos e utilização de salas.
- Cadastro e gerenciamento de informações.
- Modelagem e utilização de banco de dados SQLite.

**Disciplinas relacionadas:** Banco de Dados, Desenvolvimento Web e Interação Humano-Computador.

---

### 2. Projeto Integrador II — Rituá Terapias

**Repositório:** [ritua-agendamentos](https://github.com/Univesp-Projeto-Integrador-TI/ritua-agendamentos)

Evolução de um sistema de gerenciamento de agendamentos para a clínica Rituá Terapias.

**Objetivo:** modernizar a gestão da clínica, melhorar a experiência dos usuários e automatizar processos administrativos.

**Tecnologias e recursos planejados:**

- React — desenvolvimento Front-end.
- Node.js — desenvolvimento Back-end.
- SQLite — banco de dados relacional.
- APIs — integração com serviços de mensageria.
- Automação — lembretes de agendamentos.
- WCAG — acessibilidade digital.
- Cloud Computing — implantação em ambiente de nuvem.
- Git e GitHub — versionamento e colaboração.

**Principais funcionalidades:**
- Cadastro e gerenciamento de funcionários.
- Cadastro e gerenciamento de salas.
- Criação, edição e exclusão de agendamentos.
- Organização dos horários da clínica.
- Automação de lembretes.
- Melhorias na interface e usabilidade.

**Foco:** desenvolvimento de uma aplicação web responsiva, acessível e preparada para utilização em dispositivos móveis.

### 3. Infraestrutura — RuneScape: Dragonwilds

**Projeto:** Administração de servidor dedicado e infraestrutura em nuvem.

Experiência prática de configuração e manutenção de infraestrutura para hospedagem de servidor de jogo.

**Tecnologias e ferramentas:**

- Oracle Cloud Infrastructure (OCI).
- Ubuntu Server 24.04.
- Linux e administração de servidores.
- WireGuard — VPN e comunicação segura.
- Configuração de redes e portas.
- PowerShell e scripts de automação.
- Diagnóstico de processos e conectividade.

**Objetivo:** construir e administrar uma infraestrutura de servidor dedicado, com conectividade remota e gerenciamento de rede.
